# Spring Data Redis

Plug Redis into your Spring application with minimal effort

[Spring Data Redis](https://spring.io/projects/spring-data-redis) integrates Redis with the [Spring framework](https://spring.io/projects/spring-framework), letting you plug Redis into your Spring application with minimal effort. It works with the [Lettuce](/docs/latest/develop/clients/lettuce/) and [Jedis](/docs/latest/develop/clients/jedis/) clients, so Spring applications can take advantage of those clients' connection features as well as Spring's own abstractions.

The pages in this section describe recipes for using Redis from Spring Data Redis:

[[integrate/spring-framework-cache/cache|Use Redis with the Spring cache abstraction]] shows how to use Redis as the storage for Spring's cache abstraction.
[[integrate/spring-framework-cache/geo-failover|Client-side geographic failover]] shows how to configure resilient connections that automatically fail over between Redis endpoints.
