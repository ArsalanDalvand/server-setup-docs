# redis-di list-contexts

Lists all contexts

Lists all contexts from the `~/.redis-di` context file and indicates which one is active. See the
[[integrate/redis-data-integration/reference/cli#contexts|CLI reference overview]]
for more about contexts.

## Usage

```
redis-di list-contexts [flags]
```

## Options

This command takes only the
[[integrate/redis-data-integration/reference/cli/redis-di#global-options|global options]].

## Example

```bash
redis-di list-contexts
```
