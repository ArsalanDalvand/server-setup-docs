# Redis Cloud REST API

Describes the Redis Cloud REST API and links to additional info

            Redis Cloud
          

The [[operate/rc/api/api-reference|Redis Cloud REST API]] helps you manage your Redis Cloud databases programmatically.

You can use the API to:

Create or manage databases
Define or change hosting credentials
Audit access via logs
Backup or import databases
