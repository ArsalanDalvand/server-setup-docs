# Redis Cloud changelog (July 2023)

New features, enhancements, and other changes added to Redis Cloud during July 2023.

            Redis Cloud
          

This changelog lists new features, enhancements, and other changes added to Redis Cloud during July 2023.

## New features

### New ACL capabilities

You can now use [[operate/oss_and_stack/management/security/acl#selectors|Selectors]] and [[operate/oss_and_stack/management/security/acl#selectors|Key Permissions]] in your [[operate/rc/security/access-control/data-access-control/configure-acls|ACL rules]] for all Redis 7.2 databases.

In addition, the admin console now returns an error if you try to enter an invalid ACL. It will also associate the ACL rule with the supported database version when you [add it to a role](/docs/latest/operate/rc/security/access-control/data-access-control/create-roles/).

## Deprecations

RedisGraph is no longer available when you select Redis Stack on Fixed. For more information, see the [RedisGraph end of life announcement](https://redis.com/blog/redisgraph-eol/).
You are no longer able to [[operate/rc/security/access-control/data-access-control/configure-acls|create an ACL rule]] using the rule builder. Instead, use [ACL syntax](https://redis.io/docs/management/security/acl/) to define your ACL rules.
