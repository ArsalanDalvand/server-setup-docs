# Redis Cloud changelog (May 2023)

New features, enhancements, and other changes added to Redis Cloud during May 2023.

            Redis Cloud
          

This changelog lists new features, enhancements, and other changes added to Redis Cloud during May 2023.

## New features and enhancements

### Cloud API - Fixed plans support

The [[operate/rc/api|Redis Cloud API]] supports new endpoints to manage fixed subscriptions and databases.

The new fixed endpoints can be viewed in the [Redis Cloud Swagger UI](https://api.redislabs.com/v1/swagger-ui/index.html#/Subscriptions%20-%20Fixed). For more information about using the Redis Cloud API, see [[operate/rc/api/get-started/use-rest-api|Use the REST API]].

### Active-Active access roles

For [Active-Active databases](/docs/latest/operate/rc/databases/active-active/), you can now define roles with different levels of access for different regions.

For more information, see [Active-Active roles](/docs/latest/operate/rc/security/access-control/data-access-control/active-active-roles/).
