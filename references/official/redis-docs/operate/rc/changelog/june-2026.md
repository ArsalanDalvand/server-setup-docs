# Redis Cloud changelog (June 2026)

New features, enhancements, and other changes added to Redis Cloud during June 2026.

            Redis Cloud
          

## New features

### Billing Admin API access

Users with the [[operate/rc/security/access-control/access-management#team-management-roles|Billing Admin role]] can now use the [[operate/rc/api|Redis Cloud REST API]] to perform billing operations. See [[operate/rc/security/access-control/access-management#team-management-roles|Team management roles]] for the full list of permissions for each role.

### Redis Data Integration

[[operate/rc/rdi|Redis Data Integration (RDI)]] is now generally available on Redis Cloud. RDI lets you create data pipelines that ingest data from a supported primary database into Redis, so your cache stays in sync with live data and is always ready for queries.

See [[operate/rc/rdi|Data Integration]] to learn how to set up data pipelines with Redis Cloud.
