# Redis Cloud changelog (March 2024)

New features, enhancements, and other changes added to Redis Cloud during March 2024.

            Redis Cloud
          

## New Features

### Fixed subscriptions through Google Cloud Marketplace

You can now use your [Google Cloud Marketplace](/docs/latest/operate/rc/cloud-integrations/gcp-marketplace/) account to pay for your Fixed subscriptions as well as your Flexible subscriptions.

### Active-Passive with TLS

[Active-Passive](/docs/latest/operate/rc/databases/migrate-databases/#sync-using-active-passive) now supports source databases that require connections over TLS. See [Migrate data](/docs/latest/operate/rc/databases/migrate-databases/) for more information.
