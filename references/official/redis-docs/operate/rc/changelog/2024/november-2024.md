# Redis Cloud changelog (November 2024)

New features, enhancements, and other changes added to Redis Cloud during November 2024.

            Redis Cloud
          

## New Features

### Pro subscription version upgrade

You can now upgrade all databases in your Pro subscription from your [[operate/rc/subscriptions/view-pro-subscription|subscription page]].

Select Version upgrade to request to upgrade your subscription and databases if there is a later version available.

[](/docs/latest/images/rc/button-version-upgrade.png)

Select the version to upgrade your databases from the list and select Upgrade to submit the upgrade request.

[](/docs/latest/images/rc/version-upgrade-request.png)

The upgrade will start one week from your request, according to your subscription's [[operate/rc/subscriptions/maintenance/set-maintenance-windows|maintenance windows]].

Review the [[operate/rc/changelog/2023/june-2023#redis-72-breaking-changes|7.2 breaking changes]] or [[operate/rc/changelog/2024/july-2024#redis-74-breaking-changes|7.4 breaking changes]] before you request to upgrade.
