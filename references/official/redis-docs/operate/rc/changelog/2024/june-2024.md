# Redis Cloud changelog (June 2024)

New features, enhancements, and other changes added to Redis Cloud during June 2024.

            Redis Cloud
          

## Enhancements

### Redis Cloud Essentials support for Terraform

The [Redis Cloud Terraform provider](/docs/latest/integrate/terraform-provider-for-redis-cloud/) now supports provisioning Redis Cloud Essentials databases. It also supports Active-Active databases with advanced capabilities.

See the [Redis Cloud Terraform provider changelog](https://github.com/RedisLabs/terraform-provider-rediscloud/blob/main/CHANGELOG.md) for full version content.

See [Get started with Terraform](/docs/latest/integrate/terraform-provider-for-redis-cloud/get-started/) to learn how to install the Redis Cloud provider and create a subscription and database.
