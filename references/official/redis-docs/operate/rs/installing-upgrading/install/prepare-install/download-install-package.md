# Download a Redis Software installation package

Download a Redis Software installation package.

            Redis Software
          

To download the installation package for any of the supported platforms:

Go to the [Redis download page](https://cloud.redis.io/#/rlec-downloads).
Sign in with your Redis credentials or create a new account.
In the Downloads section for Redis Software, select the installation package for your platform then select Go.

Note:
  Before you install the Linux package or AWS AMI on an AWS EC2 instance,
review the [configuration requirements for AWS EC2 instances](/docs/latest/operate/rs/installing-upgrading/install/plan-deployment/configuring-aws-instances/).
