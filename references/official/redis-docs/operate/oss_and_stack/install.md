# Install Redis Open Source

How to install Redis Open Source on your target platform

            Redis Open Source
          

You can install [[operate/oss_and_stack|Redis Open Source]] locally on your machine. Redis Open Source is available on Docker, Linux, macOS, and Windows (using Docker only).

You can also download [Redis Insight](/docs/latest/operate/redisinsight/install/), a free developer companion tool with an intuitive GUI and advanced CLI, which you can use alongside Redis Open Source.

Here are the installation and upgrade instructions:

[[operate/oss_and_stack/install/install-stack|Install Redis Open Source]]
[Upgrade Redis Open Source](/docs/latest/operate/oss_and_stack/install/upgrade/)

While you can install Redis Open Source locally, you might also consider using Redis Cloud by creating a [free account](https://redis.com/try-free/?utm_source=redisio&utm_medium=referral&utm_campaign=2023-09-try_free&utm_content=cu-redis_cloud_users).
