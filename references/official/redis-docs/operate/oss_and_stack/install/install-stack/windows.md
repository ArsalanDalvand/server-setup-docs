# Run Redis Open Source on Windows using Docker

How to run Redis Open Source on Windows

            Redis Open Source
          

## Run Redis Open Source on Windows using Docker

To install Redis Open Source on Windows, you will need to have Docker installed. When Docker is up and running, open Windows PowerShell and follow the instructions described in [[operate/oss_and_stack/install/install-stack/docker|Run Redis Open Source on Docker]]. Then, use Docker to connect with `redis-cli` as explained in that topic.

## Run Redis on Windows using Memurai

A preview of Redis Open Source 8.2 RC1 is available on Windows through [Memurai](https://www.memurai.com/get-memurai), the official Redis partner for Windows compatibility.
