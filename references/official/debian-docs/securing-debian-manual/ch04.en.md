			In order to receive information on available security updates you should subscribe yourself to the debian-security-announce mailing list in order to receive the Debian Security Advisories (DSAs). 			You should consider, also, subscribing to the [http://lists.debian.org/debian-security](http://lists.debian.org/debian-security) for general discussion on security issues in the Debian operating system.
