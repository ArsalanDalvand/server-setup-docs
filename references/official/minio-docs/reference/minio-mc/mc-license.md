# mc license

## Description

The [`mc license`](#command-mc.license) commands work with cluster registration for [MinIO SUBNET](https://min.io/pricing?jmp=docs).
Use the commands to register a deployment, display information about the cluster’s current license, or update the license key for a cluster.

## Subcommands

[`mc license`](#command-mc.license) includes the following subcommands:

Subcommand

Description

[[reference/minio-mc/mc-license-info#command-mc.license.info|`info`]]

The [[reference/minio-mc/mc-license-info#command-mc.license.info|`mc license info`]] command displays information about the MinIO deployment’s license status.
Specifically, whether the deployment uses the AGPLv3 Open Source license of the [MinIO Commercial License](https://min.io/product/subnet?ref=docs).

[[reference/minio-mc/mc-license-register#command-mc.license.register|`register`]]

The [[reference/minio-mc/mc-license-register#command-mc.license.register|`mc license register`]] command connects your deployment with your [MinIO SUBNET](https://min.io/pricing?jmp=docs) account.

[[reference/minio-mc/mc-license-update#command-mc.license.update|`update`]]

Use the [[reference/minio-mc/mc-license-update#command-mc.license.update|`mc license update`]] command to replace a license key for a deployment.
