# mc tag

## Description

The [`mc tag`](#command-mc.tag) command adds, removes, and lists tags associated to a bucket or object.

MinIO supports adding up to 10 custom tags to an object.

## Subcommands

[`mc tag`](#command-mc.tag) includes the following subcommands:

Subcommand

Description

[[reference/minio-mc/mc-tag-list#command-mc.tag.list|`list`]]

The [[reference/minio-mc/mc-tag-list#command-mc.tag.list|`mc tag list`]] command lists all tags from a bucket or object.

[[reference/minio-mc/mc-tag-remove#command-mc.tag.remove|`remove`]]

The [[reference/minio-mc/mc-tag-remove#command-mc.tag.remove|`mc tag remove`]] command removes all tags from a bucket or object.

[[reference/minio-mc/mc-tag-set#command-mc.tag.set|`set`]]

The [[reference/minio-mc/mc-tag-set#command-mc.tag.set|`mc tag set`]] command sets one or more tags to a bucket or object.
