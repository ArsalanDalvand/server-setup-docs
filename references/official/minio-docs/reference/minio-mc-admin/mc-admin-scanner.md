# mc admin scanner

## Description

The [`mc admin scanner`](#command-mc.admin.scanner) commands provide information about the [[operations/concepts/scanner#minio-concepts-scanner|scanner]] process.

## Subcommands

[`mc admin scanner`](#command-mc.admin.scanner) includes the following subcommands:

Subcommand

Description

[[reference/minio-mc-admin/mc-admin-scanner-status#command-mc.admin.scanner.status|`status`]]

The [[reference/minio-mc-admin/mc-admin-scanner-status#command-mc.admin.scanner.status|`mc admin scanner status`]] command displays a real-time summary of [[operations/concepts/scanner#minio-concepts-scanner|scanner]] information for a MinIO Server.

[[reference/minio-mc-admin/mc-admin-scanner-trace#command-mc.admin.scanner.trace|`trace`]]

The [[reference/minio-mc-admin/mc-admin-scanner-trace#command-mc.admin.scanner.trace|`mc admin scanner trace`]] command displays [[operations/concepts/scanner#minio-concepts-scanner|scanner]]-specific API operations occurring on the target MinIO deployment.
