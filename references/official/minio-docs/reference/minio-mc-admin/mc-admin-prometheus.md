# mc admin prometheus

## Description

The [`mc admin prometheus`](#command-mc.admin.prometheus) command and its subcommands provide access to MinIO Prometheus metrics.

## Subcommands

[`mc admin prometheus`](#command-mc.admin.prometheus) includes the following subcommands:

Subcommand

Description

[[reference/minio-mc-admin/mc-admin-prometheus-generate#command-mc.admin.prometheus.generate|`generate`]]

The [[reference/minio-mc-admin/mc-admin-prometheus-generate#command-mc.admin.prometheus.generate|`mc admin prometheus generate`]] command generates a metrics scraping configuration file for use with [Prometheus](https://prometheus.io/).

[[reference/minio-mc-admin/mc-admin-prometheus-metrics#command-mc.admin.prometheus.metrics|`metrics`]]

The [[reference/minio-mc-admin/mc-admin-prometheus-metrics#command-mc.admin.prometheus.metrics|`mc admin prometheus metrics`]] command prints Prometheus metrics for a cluster.
